# 🏭 제조 공정 운영 최적화 — 품질 데이터 EDA

> KAMP(인공지능 제조 플랫폼) **공정 센서 데이터**를 모아 정리하고 탐색한 학습 기록 (2024.01)

| 항목 | 내용 |
|---|---|
| 데이터 | KAMP 제조 데이터셋 — 2021.09.06 ~ 10.27 일별 센서 CSV 33개 (LoT · 시각 · pH · 온도) + 공정 불량률 CSV |
| 목표 | 흩어진 일별 파일을 하나의 분석용 데이터로 만들고, 품질에 영향을 주는 변수를 탐색 |
| 사용 기술 | Python · pandas · seaborn · Matplotlib |

<br>

## 한 일

1. **파일 자동 수집** — 폴더 안의 CSV만 골라 센서 데이터와 불량률 데이터를 구분해 불러오기
2. **시간 정보 정리** — 파일마다 날짜(`DTime`)와 시각(`Time`)을 합친 열을 만들어 하나의 데이터프레임으로 병합 (약 5만 행)
3. **데이터 확인** — 기술통계, 결측치 개수, 열별 히스토그램
4. **상관 분석** — 피어슨 상관계수와 히트맵으로 pH · 온도 관계 확인
5. **정제** — 결측치 제거, LoT · 날짜별 데이터 개수 확인 후 불량률 데이터와 연결

## 배운 점

- 현장 데이터는 **여러 파일로 흩어져 있고 형식이 조금씩 달라서**, 분석보다 모으고 정리하는 데 시간이 더 든다는 걸 경험했어요.
- 원본을 바로 고치지 않고 **복사본으로 작업**하고, 처리 단계를 함수로 나눠 다시 실행할 수 있게 만드는 습관을 들였어요.
